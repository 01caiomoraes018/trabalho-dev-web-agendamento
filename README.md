# Trabalho 1 - Desenvolvimento Web com .NET

Gerenciamento de pacientes na aplicação Agendamento, usando como base o [projeto do professor Lucas Teodoro](https://github.com/teodorolucaas/DesenvolvimentoWebDotNet/tree/main/Agendamento).

## Etapa atual

Repositório inicial organizado. O código-base foi separado localmente para revisão e ainda não foi publicado aqui.

## Etapas previstas

- Importar e executar a base do professor com PostgreSQL.
- Criar Paciente com Nome, CPF, Telefone, Endereço e Data de Nascimento, usando Data Annotations.
- Adicionar migrations e pacientes iniciais com seeding.
- Criar telas para listar, inserir, editar e remover pacientes.
- Testar as operações e preparar a entrega.

A implementação será feita por etapas. Senhas do banco devem ficar somente na configuração local.
